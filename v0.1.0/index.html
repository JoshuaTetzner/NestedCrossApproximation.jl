NestedCrossApproximation.jl

This package constructs $\mathcal{H}^2$-matrices with the nested cross approximation (NCA) [1]. An $\mathcal{H}^2$-matrix is a data-sparse representation of the matrices arising in boundary element methods: interactions between well-separated clusters are compressed into nested low-rank factors, which reduces storage and the cost of a matrix-vector product from $\mathcal{O}(N^2)$ to $\mathcal{O}(N)$ in the low-frequency regime.

The nested bases are built purely from matrix entries, so the package is kernel independent. It provides

  • three compressors for the nested bases: TopDown, BottomUp, and BatchedBottomUp,
  • the adaptive cross approximation (ACA) and the incomplete ACA (IACA) [4] of AdaptiveCrossApproximation.jl as the low-rank factorizations inside the compressors,
  • optional far-field representors based on random sampling, a Chebyshev grid, or tree-mimicry pivoting,
  • a wideband extension based on a directional subdivision of the far field [2, 3, 5] for problems that contain electrically large clusters.

Installation

Installing NestedCrossApproximation is done by entering the package manager (enter ] at the julia REPL) and issuing:

pkg> add https://github.com/JoshuaTetzner/NestedCrossApproximation.jl.git

Quick start

The package does not export any names; import what you need explicitly.

using NestedCrossApproximation: PetrovGalerkinNCA, TopDown
using AdaptiveCrossApproximation
using H2Trees
using ParallelKMeans

builder = KMeansTreeBuilder(; minvalues=100)
tree = BlockTree(
    KMeansTree(testpoints; builder=builder), KMeansTree(trialpoints; builder=builder)
)

h2mat = PetrovGalerkinNCA(
    operator,
    testspace,
    trialspace,
    tree;
    testcompressor=TopDown(; factorization=ACA(; tol=1e-4)),
    trialcompressor=TopDown(; factorization=ACA(; tol=1e-4)),
)

y = h2mat * x
